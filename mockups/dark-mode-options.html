Lector site — dark mode, six alternatives

The glare is not mainly the text. It is that --ink paints the text and every 3 px border and every hard shadow, so the page is drawn in near-white outlines. All six options split that into --line (borders) and --shadow, then trim the text down from #f2f2f2. Ratios below are text-on-paper; the current 17.6:1 is the number to beat.

CURRENTWhat ships today

#f2f2f2 text on #0a0a0a, and the same #f2f2f2 on every border and shadow. Shown only for comparison.

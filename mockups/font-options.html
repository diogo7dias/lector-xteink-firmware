Lector site — fonts, current and two alternatives each

The site requests four families site-wide: Archivo, Archivo Black, Newsreader, JetBrains Mono. Each page only paints three of them — the converter page never renders Newsreader (the ledger skin overrides every serif rule), and the guide never renders Archivo Black. Both pages download all four regardless. Below, each role is shown at the sizes the live site actually uses.
